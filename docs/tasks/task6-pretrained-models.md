## 요약

- 학습 없이도 현재값 유지보다 23~38% 낫다(Bolt small).
- **Chronos-2는 사무실·회의실에서 우리 GRU보다 낫다**(60분 48.4 vs 51.6, 122.8 vs 141.4ppm). 검증 기간에서도 같았다.

## 생각해 볼 점

**Q1. 사전학습 모델은 CO₂ 과거값만 본다. 직접 학습 모델과의 차이 중 얼마가 시간대·요일·온습도 정보 때문인가?**

검증 실습실 CO₂ 60분 MAE(ppm)로 나눠 보면 다음과 같다.

| 모델 | 입력 | MAE |
|---|---|---|
| GRU | 센서(CO₂·온도·습도)만, 과거 2시간 | 46.7 |
| GRU | + 시간대·요일 | **34.0**(−12.7) |
| GRU | + 공간 | 32.7(−1.3) |
| GRU | + 일정 | 31.1(−1.6) |
| Bolt small | CO₂만, 과거 1주 | 41.7 |
| Chronos-2 | CO₂만, 과거 1주 | 31.7 |
| Chronos-2 | CO₂만, 과거 1일 → + 온습도·시간·일정 | 60.4 → 37.9(−22.5) |

- **차이의 대부분은 시간 정보다.** GRU에서 시간대·요일이 12.7ppm을 줄였다. 공간·일정은 합쳐 2.9ppm이다. 온습도는 "센서" 묶음 안에 있어 따로 떼지 않았다.
- **사전학습 모델은 긴 과거로 시간 정보를 대신한다.** 과거 1주에는 지난 7일의 같은 시각이 다 있다. 그래서 CO₂만 보는 Chronos-2가 시간 정보를 다 넣은 GRU와 같은 수준(31.7 vs 31.1)이 됐다.
- 과거가 짧으면(1일) 공변량이 크게 돕는다(−37%). 자세한 것은 [심화 ①](../advanced/task6/01-covariates.md)에 있다.

**Q2. 과거를 얼마나 길게 줄 때 가장 잘 맞나?**

| 과거 | 1시간 | 4시간 | 1일 | 1주 |
|---|---|---|---|---|
| Bolt small 검증 정규화 MAE | 0.131 | 0.108 | 0.097 | **0.088** |
| Bolt small 검증 실습실 60분(ppm) | 103.9 | 74.8 | 58.1 | **41.7** |

- **길수록 좋고 1주가 가장 좋다.** 세 크기(tiny·mini·small) 모두 같은 순서였다.
- 직접 학습 GRU는 2시간이면 충분했다(과제 3 심화 1). 이와 반대다. GRU는 시간 특징으로 하루 주기를 이미 알지만, 사전학습 모델은 과거에서 주기를 직접 봐야 한다.
- 1주를 넘는 과거는 Bolt의 입력 한도(2,048칸 ≈ 7.1일) 때문에 시험하지 않았다.

**Q3. 같은 보드에 로컬 LLM과 함께 올려야 한다. 메모리 예산 안에 들어가나?**

보드 7,486MB 기준이고, 상한은 85%(6,363MB)로 잡았다.

| 구성 | 합계(대략) | 상한 안? |
|---|---|---|
| OS·데스크톱 1.5GB + 수집기 0.2 + 다른 계정 0.5 + 추론 서비스 1.4 | 3.6GB | — |
| + LLM 3B 4비트(2.5GB 가정) | 6.1GB | ✅(여유 0.3GB) |
| + LLM 3B + Chronos-2 상주(1.9GB) | 8.0GB | ❌ |
| + LLM 1B(1.5GB) + Chronos-2 | 7.0GB | ❌ |
| 추론 서비스를 ONNX Runtime CPU로 바꾼 뒤(−0.6GB, 과제 7) + LLM 3B + Chronos-2 CPU(1.4GB) | 6.9GB | ❌ |

- **LLM과 사전학습 모델을 동시에 상주시킬 수 없다.** 그래서 채택 의견이 "상주하지 않고 필요할 때만 띄움"이다.
- 실측 사례: Chronos-2(과거 1주, 묶음 256) 예측 중에 보드 여유가 121MB까지 떨어져 작업을 중단했다(2026-10-21 23:55).

## 메모(환경)

- Chronos-Bolt 디코더가 Triton을 부르고, Triton은 `Python.h`로 C 도우미를 컴파일한다. 시스템에 `python3-dev`가 없어(sudo 없음) `uv python install 3.12`로 받은 독립 Python의 헤더를 `C_INCLUDE_PATH`로 쓴다. `tools/pretrained`가 자동으로 설정한다.
- 예측 묶음 크기는 32다(256은 Chronos-2에서 3.8GB). 과거 1주 + 공변량은 메모리 때문에 시험하지 않았다.
