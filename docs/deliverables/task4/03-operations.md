# 과제 4 산출물 ③ 운영 제안

> **측정 조건**: [① 성적표](01-scorecard.md)와 같다(실데이터 + 주입 고장 60건, 시험 2026-05-27 ~ 07-22, 57일).
> 공간별 숫자는 결합(오토인코더 + 규칙) 기준이다. 숫자 원본: [결과 표 ③](tables/03-operations.md)
> ⚠️ 운영 임계값 0.9998은 시험 결과를 본 뒤 고른 제안값이다. 공식 판정은 검증으로 고정한 0.999다([②](02-threshold-tradeoff.md)).

## 공간별 제안

| 공간 | 경보 기준(오토인코더 분위수) | 시험 탐지(공식 0.999 → 제안) | 헛경보/일(0.999 → 제안) | 추가 조치 |
|---|---|---|---|---|
| **실습실** | **0.9998** | 20/21 → 19/21 | 1.09 → 1.12 | 센서 6대라 원인 지목이 가장 정확하다. 기준 그대로 운영 |
| **사무실** | **0.9998** | 21/27 → 19/27 | 1.09 → **0.39** | 밤 값 고정은 모델·규칙 모두 약하다. 밤 0~6시에 4시간 넘게 값이 그대로면 아침에 한 번 알린다 |
| **회의실** | **0.9998** + CO₂ 급변 규칙 끄기 | 11/12 → 10/12 | 2.47 → 0.67(규칙까지 끄면 약 0.3) | 급변 규칙 헛경보 22건이 모두 CO₂이고, 모두 평일 낮 사용 시간(09:55~17:05)이다. 10분 주기 한 칸이 올랐다 내려오는 모양이라 짧은 출입·문 열기와 튄 값이 구별되지 않는다 |

- 회의실 CO₂ 급변 규칙을 끄면 헛경보가 최대 22건(0.39/일) 더 줄어든다(다른 경보와 겹쳐 묶이는 것은 빼지 않은 추정). 단, 회의실 CO₂ 튄 값은 놓칠 수 있다.
  - 회의실 센서는 10분 주기 1대라 사람의 짧은 움직임과 튄 값을 한 칸으로는 구별하기 어렵다.
  - 사용 시간대에는 회의실 CO₂ 급변을 끄고, 빈 시간대(과제 5 사용 여부 = 비어 있음)에만 켜는 방식을 다음 버전 후보로 둔다.
- **전체 합**: 제안 설정이면 시험 기준으로 약 1.8회/일이다(목표 1회는 아직 못 미침). 여름 데이터 재학습이 근본 해결이다([②](02-threshold-tradeoff.md) 결론).

## 알림 대상

| 고장 종류 | 판단 근거 | 알림 대상 | 권장 행동 | 재알림 |
|---|---|---|---|---|
| 튄 값 · 값 고정 · 범위 밖 · 데이터 끊김 | 원인이 장치 하나 | **센서 관리 담당** | 센서 전원·배터리·게이트웨이 확인 | 30분마다, 3주기 정상이면 해제 |
| 영점 틀어짐 | 새벽 CO₂가 외기(약 450ppm)보다 높게 유지(심화 2) | 센서 관리 담당 | 교정 일정 잡기(급하지 않음, 하루 1번 알림) | 하루 1번 |
| 냉방 정지 | 공간 온도 전체가 수업 중 계속 오름 | **시설 담당** | 실내기 상태 확인(xflow 운전 상태와 대조) | 30분마다 |
| 환기 정지 | 사용 중 CO₂ 상승 폭이 평소보다 큼 | 시설 담당 + **공간 사용자** | 창문 열기, 환기 장치 확인 | 30분마다 |
| 원인 불명 이상(점수만 높음) | 원인 센서 기여가 고르게 퍼짐 | 시설 담당(확인 요청) | 현장 확인. 헛경보면 기록 | 재알림 없음 |

- 같은 고장에 매분 알리지 않는다. 생김 → 30분 재알림 → 3주기 정상이면 해제한다(과제 8 경보 상태 기계와 같다).
- 이상 경보는 "확인 요청" 수준으로 보낸다. 시험 헛경보가 하루 2회 안팎이라, 바로 출동하게 하면 곧 무시된다.

## 이 제안을 어떻게 다시 확인하나 (생각해 볼 점 Q3)

실데이터에는 고장 정답이 없다. 다음 세 가지로 확인한다.
1. **주입 시험을 정기적으로 돌린다**: 새 계절 데이터에 같은 고장 5종을 넣고 탐지율·지연을 다시 잰다(`anomaly inject && anomaly evaluate`).
2. **경보 기록에 사람이 답을 단다**: 시설·센서 담당이 경보마다 "실제 고장 / 사용 / 모름"을 남긴다. 한 달이면 실제 헛경보율이 나온다.
3. **알려진 사건과 대조한다**: 과제 2 사건 후보(화재·누수·밀집)와 겹치는 경보는 실제 이상일 가능성이 높다. 시험 기간에 5건이 겹쳤다.
