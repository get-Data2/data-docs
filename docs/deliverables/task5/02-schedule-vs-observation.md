# 과제 5 산출물 ② 일정 기반 정답과 직접 관찰의 차이

> **측정 조건**: 일정 정답은 고정 일과표(평일 09:00~11:30·13:00~18:00, 공휴일 제외; 실습실·사무실)다.
> 직접 관찰은 실시간 수집 기간(2026-10-20~)에 사람이 기록한다(`state observe`, [관찰 안내](observation-guide.md)).
> ⏸ **관찰 기록이 목표에 크게 못 미친다**(2026-10-21 22시 기준: 실습실 1회, 사무실·회의실 0회). 관찰 기반 비교는 기록이 쌓인 뒤 채운다. 아래는 지금 낼 수 있는 근거다.

## 관찰 진행 상황

| 공간 | 목표 | 현재 |
|---|---|---|
| 실습실 | 수업일 2일, 경계(09:00·11:30·13:00·18:00 ±30분) 4회 | 10-21 16:08 빈 방 → 16:09 사용 시작(20명). **끝 시각이 기록되지 않아 열린 구간** |
| 사무실 | 수업일 2일, 경계 4회 | 없음 |
| 회의실 | 회의 2회 + 빈 시간 2시간 | 없음 |
| 전체 | 20시간 | 실습실 1구간(열린 상태) |

열린 구간은 실제 퇴실 시각으로 닫아야 한다. 예: `state observe lab empty --at "2026-10-21 18:05" --by <머리글자>`. 그 전까지 평가에서 관찰 칸은 0칸으로 잡힌다.

## 관찰 없이 보이는 일정 정답의 틀림

관찰은 부족하지만, 센서 데이터와 과제 2 진단으로 **일정 정답이 틀리는 곳**은 이미 보인다.

| 공간·시간 | 일정 정답 | 데이터가 보여 주는 것 | 근거 |
|---|---|---|---|
| **사무실 점심(11:30~13:00)** | 비어있음 | CO₂ 중앙값이 11시 1,036 → 12시 1,020ppm으로 거의 그대로다. 사람이 나갔다면 내려가야 한다 | 시험 기간 평일 시각별 중앙값. 과제 2: 사무실 점심 반응 37% |
| **사무실 18~20시** | 비어있음 | 16시 1,424 → 18시 1,280 → 20시 1,061ppm으로 천천히 내려간다. 남아서 일하는 사람이 있거나, 환기가 약해 CO₂가 오래 남는다 | 같음. 사무실 감쇠 시간 상수 약 5시간(과제 8 심화 1) |
| 실습실 수업일 | 시간표대로 | 09:00 뒤 5분 안에 반응한 날이 99%다 | 과제 2 진단서 |
| 실습실 어긋난 날 | 수업 | 학습 기간의 약 11%가 일과표와 어긋난 날(휴강·행사) | 과제 2 |

- 사무실에서 분류기의 "비어있음 → 사용중" 오류 3,256칸 중 가장 많은 시간대가 바로 **12시(402칸)·18시(389칸)·20시(356칸)**다([③](03-error-cases.md)).
- 이 오류의 상당수는 모델이 틀린 것이 아니라 **정답이 틀린 것**일 수 있다. 이것을 가르는 것이 직접 관찰의 목적이다.

## 관찰이 채워지면 볼 것

1. **일정 정답의 오류율**: 관찰 칸에서 일정 정답과 관찰이 다른 비율. 공간·시간대별로 낸다. `state labels`가 "관찰과 일정 정답 불일치"를 출력한다.
2. **분류기를 두 정답으로 채점**: 일정 기준 성적과 관찰 기준 성적의 차이. 사무실 점심·저녁에서 관찰 기준 오류가 크게 줄면 "정답이 틀렸다"가 확인된다.
3. **인원별 재현율**: 관찰에 적은 인원 수로, 몇 명부터 센서로 구별되는지 본다(생각해 볼 점 "적은 인원·큰 강의실").
4. **출입문 센서 대조**: 실습실·사무실 출입문 센서(WS301) 기록과 관찰 시각을 맞춰 관찰 기록의 실수를 거른다(`state observe --check --door`). 출입문 기록은 정답·입력으로는 쓰지 않는다.
